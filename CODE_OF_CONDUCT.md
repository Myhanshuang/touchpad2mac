# Code of conduct

We want technical discussion and collaboration here to be safe, focused and
welcoming. Treat other contributors with respect, critique ideas and code
rather than people, and avoid harassment, discriminatory language, threats or
deliberate disruption.

Maintainers may edit or remove abusive content and may restrict participation
when necessary to protect contributors or the project. Good-faith technical
disagreement, including firm review feedback about correctness or safety, is
welcome when it stays specific and professional.

For conduct concerns, contact the repository maintainers privately through
the channels exposed by the GitHub repository rather than escalating in a
public issue.
